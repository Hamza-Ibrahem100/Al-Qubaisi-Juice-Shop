# عصائر القبيسي | Al-Qubaisi Juices Website 🥤

موقع إلكتروني احترافي ومتجاوب بالكامل لمحل العصائر والسموذي **"القبيسي"**، تم بناؤه باستخدام **React.js** و **Bootstrap 5** كصفحة واحدة تفاعلية (SPA) بتصميم عصري وألوان حيوية مستوحاة من الطبيعة (الأخضر النضر، البرتقالي الساطع، والأصفر الشمسي).

## 🌟 الميزات الرئيسية (Key Features)

* **تصميم متجاوب بالكامل (Fully Responsive):** تجربة مستخدم مثالية على الهواتف والأجهزة اللوحية والمكتبية.
* **سلة تسوق تفاعلية (Interactive Shopping Cart):** إمكانية إضافة العصائر، تحديد الكميات، وحساب المجموع الكلي فورياً.
* **إتمام الطلب عبر WhatsApp:** عند الضغط على إتمام الطلب، يتم إنشاء رسالة مشفرة ومفصلة بقائمة العصائر المطلوبة وأسعارها وإرسالها مباشرة لرقم WhatsApp الخاص بالمتجر.
* **تصميم بالاتجاه الصحيح (RTL Support):** دعم كامل للغة العربية باتجاه اليمين إلى اليسار مع خطوط مخصصة (خط Cairo للعربية و Outfit للإنجليزية).
* **معلومات تواصل متكاملة:** نموذج تواصل يفتح رابط WhatsApp، خريطة تفاعلية من Google Maps لموقع المحل، ومواعيد العمل.
* **ألبوم صور فائق الجودة:** صور مخصصة تم توليدها خصيصاً للمنتجات ولخلفية الموقع.

---

## 🛠️ التكنولوجيا المستخدمة (Tech Stack)

* **Core Framework:** React.js 18+ (مع Hooks لإدارة الحالة والصفحات)
* **Build Tool:** Vite
* **Styling Framework:** Bootstrap 5 (نسخة RTL) + Bootstrap Icons
* **Custom Styling:** Vanilla CSS3 لـ Glassmorphism والتأثيرات الحركية الفاخرة.

## ⚙️ إعدادات المتجر (Shop Configuration)

لتغيير رقم WhatsApp للمتجر، مواعيد العمل، الأسعار، أو إضافة منتجات جديدة، قم بتعديل ملف الإعدادات الرئيسي الموجود في المسار:
📂 `src/config.js`

لتغيير رقم استقبال الطلبات، قم بتعديل متغير `whatsappNumber`:
```javascript
export const shopConfig = {
  // ...
  whatsappNumber: "201012345678", // رقم الهاتف الدولي بدون أصفار أو علامة +
  // ...
};
```

## 🚀 تشغيل المشروع محلياً (Local Setup & Run)

لشغيل الموقع على جهازك المحلي، يرجى اتباع الخطوات التالية:

### المتطلبات المسبقة:
* تأكد من تثبيت [Node.js](https://nodejs.org) (الإصدار 16 أو أحدث).

### خطوات التشغيل:

1. قم بفتح مجلد المشروع في محطة العمل (Terminal).
2. قم بتثبيت الحزم المطلوبة (في حال لم تكن مثبتة):
   ```bash
   npm install
   ```
3. قم بتشغيل خادم التطوير المحلي:
   ```bash
   npm run dev
   ```
4. افتح المتصفح على الرابط المحلي المعروض (غالباً `http://localhost:5173`).

## 📦 النشر والرفع (Deployment)

المشروع مهيأ تماماً للنشر بنقرة واحدة على منصات الاستضافة مثل:
* **Netlify** أو **Vercel**: ما عليك سوى ربط مستودع GitHub الخاص بك أو سحب مجلد المشروع بعد البناء.
* **GitHub Pages**: يمكنك بناؤه ونشره باستخدام الأمر:
  ```bash
  npm run build
  ```
  ومن ثم رفع محتويات مجلد `dist` الناتج إلى خادم الاستضافة الخاص بك.
